# 곡선 조향 보정 중심 주행 실행 가이드

이 구성은 카메라와 LiDAR를 사용하지 않고, 실제 MORAI의 GPS·IMU를 받아서
GPS/IMU 필터, ENU EKF, 곡률 기반 속도 계획, Pure Pursuit, GPS blackout 안정화를
한 번에 시험하기 위한 독립 실행 구성이다.

카메라 차선 인식 통합 구성은 별도의
`morai_udp_ekf_curvature_camera_fallback.launch`를 사용한다. 두 구성은 모두
최종 제어 토픽 `/ctrl_cmd`를 사용하므로 동시에 실행하지 않는다.

## 1. Docker 컨테이너에서 workspace 준비

```bash
cd /root/morai_ws
source /opt/ros/noetic/setup.bash
source devel/setup.bash
```

코드를 새로 받았거나 변경한 경우에는 먼저 catkin 빌드를 한다.

```bash
cd /root/morai_ws
catkin_make
source devel/setup.bash
```

## 2. 미리보기 모드

`enable_control:=false`에서는 주행 명령을 MORAI로 보내지 않고 센서, EKF,
곡률, Pure Pursuit 결과 토픽만 확인한다.

```bash
roslaunch stability_stack morai_udp_ekf_curvature_only.launch \
  workspace_path:=/root/morai_ws \
  path_file:=/root/morai_ws/data/routes/2026_molit_comp_global_path.txt \
  morai_host_ip:=192.168.0.148 \
  enable_control:=false
```

## 3. 실제 제어 모드

미리보기에서 센서와 경로가 정상임을 확인한 뒤에만 `true`로 실행한다.

```bash
roslaunch stability_stack morai_udp_ekf_curvature_only.launch \
  workspace_path:=/root/morai_ws \
  path_file:=/root/morai_ws/data/routes/2026_molit_comp_global_path.txt \
  morai_host_ip:=192.168.0.148 \
  enable_control:=true
```

MORAI PC 주소가 바뀌면 `morai_host_ip`만 현재 주소로 바꾼다. UDP 포트가
시나리오 설정에서 달라졌다면 `gps_port`, `imu_port`, `ego_status_port`,
`control_remote_port`, `control_source_port`도 실행 시 덮어쓸 수 있다.

## 4. 확인할 토픽

```bash
rostopic hz /gps
rostopic hz /Imu
rostopic hz /localization/gps
rostopic hz /localization/gps_filtered
rostopic hz /Imu_filtered
rostopic hz /localization/odometry
rostopic echo /localization/gps_health
rostopic echo /experimental/curvature_value
rostopic echo /experimental/curvature_speed_limit
rostopic echo /experimental/curvature_steering
rostopic echo /control/curvature_only_cmd
rostopic echo /control/curvature_only_stable_cmd
rostopic echo /ctrl_cmd
```

정상적인 데이터 흐름은 다음과 같다.

```text
/gps, /Imu
  -> /localization/gps, /Imu_filtered, /localization/gps_filtered
  -> /localization/odometry
  -> /control/curvature_only_cmd
  -> /control/curvature_only_stable_cmd
  -> /ctrl_cmd
```

`/localization/gps_health`가 `GPS_BLACKOUT`이어도 기본 설정은 즉시 정지하지
않는다. EKF는 IMU 예측을 계속하고, 안정화 노드는 조향 변화율을 제한한다.
단, health 메시지 자체가 오래 끊기면 안전을 위해 정지 명령을 낸다.

## 5. 곡선 주행에서 확인할 것

- 곡률이 커질수록 `/experimental/curvature_speed_limit`과 목표 속도가 낮아지는가
- 좌·우 커브에서 `/experimental/curvature_steering`의 부호와 실제 조향 방향이 맞는가
- 급격한 조향 변화가 없고 `/control/curvature_only_stable_cmd`가 제한되는가
- 경로 마지막 점 부근에서 목표 속도가 0이 되고 차량이 정지하는가
- GPS가 일시적으로 끊겨도 `/localization/odometry`와 제어 토픽이 계속 발생하는가

이 파일의 수치들은 실제 MORAI 시나리오에서 검증해야 하는 시작값이다. 특히
`wheelbase_m`, `lookahead_min_m`, `lookahead_gain`, `lateral_accel_limit_mps2`,
`max_decel_mps2`는 차량 모델과 경로에 맞춰 조정한다.
