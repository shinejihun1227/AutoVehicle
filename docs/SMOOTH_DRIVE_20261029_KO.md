# 짧은 제어 지연과 신호 오인식 보완

기준 커밋: `045407233d1f6a33daaf4e1d240c385f2eaf4492`.
대상 브랜치는 `morai_ws_full`이며 정지선 앞범퍼 7m, 일반 상한 53.2km/h와
기존 동적 대기·회전교차로·V9 기능을 유지한다.

## 제어 연결

- 기존 중재기는 일반 주행 명령이 0.3초 지연되면 바로 브레이크 1을 보냈다.
  현재 위치가 유효하고 회전교차로 제어권이 비활성으로 확인된 경우에만,
  마지막 유효 명령을 추가 최대 0.2초 이어간다. 가속은 기존 값 이하이며
  최대 0.35, 조향은 마지막 값을 유지한다. 정지 명령을 가속으로 바꾸지 않는다.
- 계속 호출돼도 원래 명령 수신 시각을 갱신하지 않는다. 마지막 명령 이후
  0.5초를 넘기거나 위치/제어권이 불명확하면 가속 유지가 끝난다.
  새 정지·장애물·신호 제동 및 회전교차로 제어는 즉시 우선한다.
  이 유지 기능은 중재기 한 곳에만 두며 UDP 브리지·최종 제어기에 추가로
  겹쳐 넣어 유지 시간이 누적되지 않게 했다.
- 전체 경로 전송을 입력 잠금 밖으로 옮기고 제어 명령을 먼저 보낸다.
  기준 경로는 10Hz로 전송하여 수천 점 직렬화 때문에 입력 처리가 밀리는 부담을 줄였다.
- adaptive 제어기의 경로 JSON 파싱은 제어 잠금 밖에서 수행한다. 경로·속도·정지
  결과의 적용은 여전히 한 번에 한다. 중복 점을 먼저 정리해 실제 동일 경로는
  곡률 프로파일을 반복 계산하지 않는다.
- 같은 경로를 다시 받아도 실행 경로 heartbeat를 계속 발행한다. 예전 최적화에서
  같은 형상일 때 발행도 생략되어 경로 확인이 오래된 것으로 판단될 수 있던 점을 수정했다.
  원래 계획 시각을 사용하며 오래된 입력에 새 시각을 붙여 유효하게 만들지 않는다.
- V9 경로 전송의 전체 deep copy를 제거하고 header만 복사한다.
- 실제 adaptive PI에 기존 설정의 페달 변화율을 연결한다. 일반 가속/감속의
  급격한 페달 변화를 줄이며, 정지 판단의 즉시 브레이크는 유지한다.

진단 `/no_obstacle_integration/status`의 `continuation_active=true`,
`source=nominal_short_gap_continue`는 짧은 명령 공백을 이어가고 있다는 의미다.

## 신호 검출과 가중치

- `best0917.pt`는 교체하지 않았다. 가중치 파일의 names 메타데이터를 실행 없이
  확인했으며 Green/Red/Yellow/red_left/red_yellow와 일반 물체 클래스가 들어 있다.
- 색상 단어를 포함한다는 이유만으로 일반 클래스 이름을 신호로 해석하지 않게 했다.
- 신호 후보에는 기존 상자 형태 검사 외에 어두운 몸체와 작게 켜진 램프가 함께
  있는지 영상 확인을 추가했다. 넓고 단색인 녹색/빨간 간판·물체를 억제한다.
  픽셀 색으로 신호 상태나 화살표 방향을 새로 만들지는 않는다.
- 현재 경로와 연결된 같은 신호등, 또는 같은 제어 주기로 확인된 신호 그룹 내에서
  검출 점수를 비교한다. 상위 신뢰도가 0.7 이상이고 다른 상태보다 0.15 이상 높으면
  높은 점수의 상태를 선택한다. 동일 검출을 복제해도 투표수가 늘지 않는다.
  점수 차이가 작은 충돌·다른 교차로·다른 진행 방향은 높은 점수만으로 통과시키지 않는다.
- 예: 같은 신호등의 GREEN 0.94 / RED 0.55는 GREEN,
  RED 0.96 / GREEN 0.60은 RED, GREEN 0.82 / RED 0.80은 확인 보류다.
  빨간 원형 램프+좌회전 화살표 조합은 기존 RED_LEFT 의미를 보존한다.
- 비교는 원본 영상의 새 프레임에서 이루어지며 기존 연속 녹색 확인을 거쳐 출발한다.
  임계값은 `config/curvature_signal.yaml`의 `signal_confidence_margin`이다.

## 실행 및 조정

기존 ROS 환경에서 업데이트·빌드한 뒤 같은 실행기를 사용한다.

```bash
bash RUN_INTEGRATED.sh drive
```

주요 실행 인자:

- `nominal_gap_grace_sec:=0.2`: 짧은 일반 명령 지연의 추가 유지 시간. 0이면 끈다.
  최대 0.3초까지만 허용한다. 위치·신호·장애물 판정 중단을 허용하는 설정이 아니다.
- `yolo_signal_visual_filter:=1`: 몸체/램프 외형 확인. 현장 영상에서 실제 램프가
  걸러지는지 로그 `CAM4 rejected signal appearances`와 함께 확인한다.

## 검증 범위

`integration_tests/run_offline.py`로 변경된 명령 유지·만료, 정지 우선,
경로 시각/형상 캐시, 신호 점수 비교·방향 보존, 색상 간판 억제를 검사한다.
카메라 입출력 시각 및 기존 신호/정지 회귀 검사도 포함한다.

현재 테스트는 모의 제어 입력과 합성 픽셀 영상이다. 실제 조명·안개·노출과
모델 오검출 사례 영상에 대한 성능 수치는 확보하지 않았다. MORAI 주행과 ROS 빌드,
카메라 미리보기 렌더링·HTTP는 이 검증의 완료 범위에 포함하지 않는다.
추가 미리보기 테스트 시도는 로컬 환경의 영상 의존성/소켓 제한으로 완료하지 못했다.

이번 최종 오프라인 검증: **427개 통과**. 자세한 범위는
`SMOOTH_DRIVE_VALIDATION.json`에 기록했다.
